# UX 카피·접근성

## 보이스 (10줄)

1. 해요체. "~합니다", "~하십시오" 쓰지 않는다.
2. 주어는 사람. "레시피가 등록되었습니다" 대신 "레시피를 올렸어요".
3. 능동형·긍정형. 기능에 필요 없는 말은 뺀다.
4. 숫자와 기한을 쓴다. "곧" 대신 "1~2일 안에".
5. 부정 소식은 사실 → 이유 → 다음 할 일 순서.
6. 잘못은 우리 탓. "입력이 잘못됐어요" 대신 "이 형식은 받을 수 없어요. 영문 소문자·숫자·밑줄로 3~15자예요".
7. 금액은 "12,900원", 크레딧은 "500C".
8. 레시피·버튼 이름은 「」로 감싼다: 「SAME 하기」, 「라이브러리에서 열기」.
9. 서비스 고유 용어는 그대로: SAME, SAME 인증, 레시피, 플레이그라운드, 크레딧.
10. 버튼 라벨은 동작으로 끝낸다: 「다시 결제하기」, 「고치러 가기」.

## 금지어

- "검증", "인증"(SAME 인증·본인인증 제외), "보장", "100%", "무조건". 증빙 있는 전문 영역 배지(「세무사 검수」)만 예외.
- 미리 체크된 동의, 총액을 숨기는 흐름(다크패턴 규정).

## 접근성

- 자동 넘김 배너: 5초, 호버·포커스 시 멈춤, 멈춤·이전·다음 버튼, 직접 넘기면 자동 넘김 끔, `prefers-reduced-motion`이면 처음부터 멈춤(WCAG 2.2.2).
- 폼 오류: 칸 아래 오류 문구 + 첫 오류 칸으로 포커스 이동, `aria-describedby`로 연결.
- 이미지·결과물에 대체 텍스트. 결과물에는 「AI 생성」 표시를 시각적·텍스트로 모두.
- 키보드: GNB 마켓 하위 메뉴는 Enter로 열고 Esc로 닫는다. 팝업은 포커스를 가두고 닫으면 원래 버튼으로 돌려준다.
- 토스트는 디자인 시스템 `ds/feedback/Toast`. 중요한 오류는 토스트만으로 알리지 않는다.
