# 실패 처리 매트릭스 (24행)

모든 경로는 `settle_cell` 한 번으로 끝난다. 중복 웹훅·sweeper 경합·재시도는 `noop`. 각 행은 테스트 하나 이상과 짝이 된다(테스트 이름 `FM-<n>`).

| # | 상황 | 감지 | 셀 상태 | 크레딧 | 사용자 문구(초안) | 운영 메모 |
|---|---|---|---|---|---|---|
| 1 | 크레딧 부족 | `start_run`이 `INSUFFICIENT_CREDITS:n` | 생성 안 함 | 홀드 없음 | 충전 창 + 「N크레딧이 모자라요」 → 충전 뒤 같은 입력으로 재실행 | 와이어프레임 PLAY c |
| 2 | 입력이 우리 모더레이션에 걸림 | 사전 검사 | 없음 / `blocked` 기록 | 홀드 없음 | 「안전 필터에 걸려 만들지 않았어요 · 크레딧은 차감되지 않았어요」 | 범주만 기록, 프롬프트 기록 금지 |
| 3 | 제출 시 공급자 거절(4xx 검증·정책) | 제출 응답 | `blocked` / `failed` | release(`safety_block` / `invalid_input`) | 안전: #2와 같음 / 입력: 「입력값을 확인해 주세요」 | 4xx는 과금 없을 것으로 추정 |
| 4 | 생성 중·후 공급자 안전 차단 | 웹훅 오류(정책 코드) | `blocked` | release(`safety_block`), 「차감 없음」 | #2와 같음 | 공급자가 과금하면 누수(미확인) |
| 5 | 모델·공급자 오류(5xx) | 웹훅 `ERROR`/`failed` | `failed`(시작 전이면 자동 재시도 ≤1) | release(`model_error`) → 「반환」 줄 | 「모델 오류로 실패했어요 · N크레딧을 돌려드렸어요」 | 과금됐을 수 있으면 자동 재시도 금지 |
| 6 | 결과가 우리 사후 모더레이션에 걸림 | finalize | `blocked` | release(`safety_block`) | #2와 같음 | 공급자는 과금 → 누수 |

| 8 | 웹훅 유실 | sweeper(`submitted`/`running` 그대로) | 조회로 finalize | 평소대로 | (약간 늦음) | Replicate 1시간, fal 7일 안에 조회 |
| 9 | 웹훅 중복·순서 뒤바뀜 | inbox unique, `settle_cell` noop | 그대로 | 그대로 | — | 중복에는 200 |
| 10 | `provider_request_id` 저장 전 웹훅 도착 | `?cell=` + 토큰으로 셀 찾기 | 정상 | 정상 | — | 페이로드에서 공급자 id 채우기 |
| 11 | 서명 불일치·재전송 타임스탬프 | 검증 실패 | 그대로 | 그대로 | — | 401 + 알림(위조 시도 가능) |

| 16 | 사용자 취소 | 클라이언트 → 공급자 취소 | `canceled` | 실행 전이면 release(`user_cancel`) | 「취소했어요 · 크레딧을 돌려드렸어요」 / 실행 중이면 취소 숨김 | 크레딧 약관에 명시 |
| 17 | 홀드와 제출 사이 서버 크래시 | sweeper: 2분 넘게 `queued` + 공급자 id 없음 | 재제출 또는 `failed` | 포기하면 release | #5와 같음 | 홀드 `expires_at`이 최후 안전장치 |

| 20 | 견적과 실행 사이 가격 변경 | `estimate_token` 불일치 | 없음 | 없음 | 「가격이 바뀌었어요 · 다시 확인해 주세요」 | 가격 버전 관리 |

## 내역 표시

| 원장 | 크레딧 내역 줄 |
|---|---|
| `hold` → `capture` | 「사용」 |
| `release` 사유 `model_error` / `timeout` / `output_lost` | 「반환」 |
| `hold` + `release` 사유 `safety_block` | 한 줄 「안전 필터 · 차감 없음」 또는 숨김 |

## 열린 질문

- 공급자가 안전 차단·실행 중 취소를 과금하는지(행 4, 6, 7, 16 누수 추정 불가)
- 모델별 지연 p50/p95 → `deadline_at` 값(이미지 5분, 영상 20분은 자리표시). W1 스파이크로 측정
