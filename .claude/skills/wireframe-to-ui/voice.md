# SAMEPLZ 보이스

규칙 원문: `.claude/rules/ux-copy-a11y.md`. 이 파일은 자주 쓰는 문구 모음이다. 와이어프레임 문구가 있으면 그것이 우선이다.

## 원칙

- 해요체, 능동형, 긍정형. 주어는 사람.
- 숫자·기한을 쓴다. 금액 "12,900원", 크레딧 "500C".
- 부정 소식은 사실 → 이유 → 다음 할 일.
- 잘못은 우리 탓. 사용자를 탓하지 않는다.
- 버튼·레시피 이름은 「」.
- 금지어: 검증, 보장, 100%, 무조건, (SAME 인증·본인인증 외의) 인증. 증빙 있는 「세무사 검수」 배지만 예외.

## 버튼

| 상황 | 문구 |
|---|---|
| 유료, 안 받음 | 「SAME 하기」 |
| 무료 | 「무료로 SAME 하기」 |
| 받음 | 「라이브러리에서 열기」 |
| 내 레시피 | 「새 버전 올리기」 |
| 판매 중지, 받은 사람 | 「받은 버전 열기」 |
| 플레이그라운드로 | 「바로 만들어 보기」 |
| 체험 다 씀 | 「SAME 하고 계속 만들기」 |
| 결제 실패 후 | 「다시 결제하기」 |
| 검사 실패 | 「고치러 가기」 |
| 반려 뒤 | 「고쳐서 다시 제출」 |
| 초안 복귀 | 「이어서」 / 「새로 시작」 |
| 탈퇴 전 | 「크레딧 환불 먼저」 |

## 띠·안내

- 공유 링크로 들어옴: 「링크로 들어옴」
- 결제 유입: "직접 유입(수수료 5%)" / "마켓 유입(수수료 15%)"
- 원문 열기 확인: "열면 환불이 제한돼요. 결과물과 미리보기로 충분히 확인했나요?"
- 철회 제한 동의: "원문을 열거나 파일을 받으면 디지털콘텐츠 제공이 시작되어 청약철회가 제한됨에 동의합니다(열기 전 7일 이내 전액 환불)"
- 결제 진행 동의: "주문 내용 확인 및 결제 진행 동의"
- 구매 버튼 위: "미리보기·체험 1회로 먼저 확인할 수 있어요"
- 결제 실패: "결제되지 않았어요"
- 플레이그라운드 첫 실행 고지: "이 화면의 결과물은 생성형 AI로 만들었어요"
- 얼굴 사진 동의: "본인 사진이거나 사진 속 인물의 동의를 받았어요 · 생성에만 쓰이고 학습에 쓰이지 않으며 N일 뒤 자동 삭제돼요"
- 가격 변경(409): "가격이 바뀌었어요"
- 비회원 SAME 인증 미리보기: "SAME 한 뒤 올릴 수 있어요"
- 받은 게 없음: "먼저 레시피를 받아 보세요"
- 라이브러리 빈 화면: "무료 레시피부터 하나 받아 봐요"
- 프로필 미저장: "저장하지 않은 변경이 있어요"
- 충전 안내: "1크레딧=10원 · 생성에만 사용 · 보너스 먼저 사용 · 유료 유효기간 5년 · 보너스 유효기간 N일 · 결제 후 7일 이내 미사용 시 전액 환불, 이후 미사용 유료분은 X% 공제 후 환불 · 보너스 환불 불가" (N·X는 D3 결정 뒤 확정)

## 0건

- 다른 카테고리에 있음: 「스킬에 1개 있어요」 · 「마켓 전체에 N개」
- 어디에도 없음: 인기 검색어 칩 10개 + 「필터 초기화」

## 라이선스·정책(GUIDE)

- "개인·업무 모두 쓸 수 있어요. 원문을 다시 팔거나 나눠 주는 건 안 돼요"
- 안전 검사: "검증·인증이 아니에요"라는 취지로 1~2일 사람 확인을 설명
