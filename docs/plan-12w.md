# MVP 7주 계획 (W1 = 2026-10-05 ~ W7 = 2026-11-22, 무료 출시)

> 파일 이름은 훅·스킬·문서가 이 경로를 읽기 때문에 `plan-12w.md`를 그대로 쓴다. **내용은 7주 MVP 계획이다.** 이전 12주 계획(유료 판매·결제·정산 포함)은 아래 「유료 전환 단계」로 옮겼다.

창업자는 아직 사업자등록을 하지 않는다. 그래서 MVP에는 **PG 계약, 통신판매업 신고, PortOne 본인인증이 없다.** 레시피는 전부 무료로 받고, 플레이그라운드는 매월 주는 무료 크레딧으로만 돈다. 실결제·환불·정산은 없다.

임계 경로는 **생성 비용과 남용**이다. 무료 생성은 돈을 받지 않고 공급자 비용만 나가므로, 계정별 일일 한도·IP/기기 레이트 리밋·전체 월 예산과 자동 킬 스위치가 출시 조건이다(D11·D12·D13). 그다음이 fal 동시성과 네이버·구글 색인(약 2주)이다.

> SessionStart 훅이 아래 주간 표의 "외부 일정"과 "주말 게이트" 열을 읽는다. **열 순서를 바꾸지 말고, 칸 안에 `|` 문자를 쓰지 않는다.**

## 출시 판단(go/no-go)

1. 무료 레시피 40개 이상(목표 60)

4. 실사용자 SAME 인증 40건

6. 개인정보처리방침·이용약관·금지 콘텐츠 정책·AI 고지 게시

## 유료 전환 단계 (사업자등록 후)

MVP 뒤, 판매를 열기로 하면 아래 순서로 간다. **카드사 심사가 최대 90일**이라 유료 출시 예정일보다 **약 3개월 앞서** 토스 신청을 건다.

1. 사업자등록(개인사업자) → 통신판매업 신고(약 3일)
2. 토스페이먼츠 신청(퀵오픈 대상 업종 여부 확인, 아니면 일반 계약) + 지급대행 계약(D7), 유료 출시 약 3개월 전
3. PortOne 본인인증 채널(판매자 등록·19세 미만 차단, D5 재검토), 카카오 비즈 앱 전환(이메일 필요 시), 알림톡 발신프로필·템플릿
4. 변호사·세무사: D1 포크 로열티, D2 판매자 소득, D3 크레딧 선불 면제·환불, D9 판매자 신원정보, 판매자 약관·통신판매중개 고지
5. 개정 전자금융거래법(2026-12-17 시행) 영향 확인 — 지급대행 구조
6. 개발: PAY·ORD·CRD 충전·환불, 쿠폰·수수료(5%/15%)·포크 로열티, 「열기 전 7일」 환불과 m:openConfirm, 체험(D6 재검토), m:verify, 정산 배치·지급대행, SELL 매출·정산 탭, `docs/features.json`의 `"phase": "paid"` 항목
7. 대기 명단(`creator_waitlist`)에게 오픈 알림
