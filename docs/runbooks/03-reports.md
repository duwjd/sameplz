# 03 신고

**첫 답은 1영업일 안에** 한다(GUIDE-05, 약관). 화면은 `/admin/reports`(신고함)다. 오래된 신고부터 보인다.

## 알림
- 접수 뒤 **20시간** 동안 답이 없으면 운영 웹후크(`OPS_ALERT_WEBHOOK_URL`)로 한 번 알린다.
  - 1분 sweeper가 `pending_sla_alerts()`로 찾고, 2xx를 받은 뒤 `mark_sla_alerts`로 표시한다. 신고마다 한 번만 간다.
  - 웹후크 변수가 없으면 알림이 가지 않는다. 신고함 카드의 「20시간 무응답」 배지로 직접 본다.

## 카드에서 보는 것
- 사유 4종: 설명과 달라요 · 이상한 지시·악성 코드 의심 · 남의 결과물 · 금지된 내용
- 대상(레시피 / 갤러리 글)과 지금 상태, 신고자, 접수 시각
- 신고자가 그 레시피를 **받은 시각·열어 본 시각**(「아직 안 열어 봄」 / 「받은 적 없음」)
- 같은 대상에 열린 신고 수(「같은 대상 신고 N건 더」)
- 공개 중·판매 중지면 「레시피 상세 열기」

## 처리
1. 대상을 확인한다. 원문이 필요하면 심사 상세(`/admin/reviews/<versionId>`)의 diff를 본다. 원문은 화면을 찍거나 옮기지 않는다.
2. 「결정」을 고른다.

| 결정 | 하는 일 | 사유 |
|---|---|---|
| 기각 (그대로 두기) | 대상은 그대로 | 없음 |
| 레시피 판매 중지 | `live → stopped`. 받은 사람은 계속 사용 | 필수(`OPS_REASONS`) |
| 레시피 게시중단 | 모두에게 숨김, 받은 사람도 못 씀 | 필수 |
| 이 갤러리 글 숨기기 | 갤러리 글 `hidden`(글 신고에만 보임) | 답변이 사유로 남음 |

- 갤러리 글 신고에서 판매 중지·게시중단을 고르면 **그 글의 레시피**에 적용된다.
- 판매 중지와 게시중단 차이는 런북 06.
3. 「답변」을 쓴다. **필수, 200자까지**(신고자 알림 본문 한도).
   - 결정을 바꾸면 `src/lib/admin/copy.ts`의 `REPORT_ANSWER_TEMPLATE`(dismiss·stop·takedown·hide_post)이 채워진다. 사안에 맞게 고쳐 보낸다.
   - 해요체, 사실 → 이유 → 다음 할 일. "검증·인증·보장"을 쓰지 않는다.
4. 보내면 `admin_resolve_report`가 **같은 대상의 열린 신고를 모두 닫고**, 신고자마다 알림(`report_answered`)을 보낸다. 같은 대상의 다른 신고에 따로 답하지 않는다.

- 이미 같은 상태(예: 이미 게시중단)면 조치는 건너뛰고 답변만 나간다.
- 조치가 안 되는 상태(예: 비공개 레시피 판매 중지)면 신고는 닫히지 않는다. 화면 오류(「지금 상태에서는 할 수 없는 조치예요.」)를 보고 다른 결정을 고른다.

## 사유별 메모
- **남의 결과물**: 런북 05(저작권). 게시중단 사유는 `rights_claim`.
- **금지된 내용**: 불법이 분명하면 런북 09. 명예훼손·사생활은 임시조치(최대 30일).
- **설명과 달라요**: MVP는 무료라 환불이 없다. 결과가 반복해서 다르면 판매 중지(`misleading`).
- **이상한 지시·악성 코드**: 확인되면 게시중단(`policy_violation`) + 크리에이터 제재(런북 08).
- 같은 크리에이터가 반복하면 런북 08.

## 기록
- 조치·답변 모두 `admin_actions`에 남는다(`recipe_stop`·`recipe_takedown`·`post_hide`·`report_dismissed`·`report_actioned`).
- 신고함에서 못 하는 일(예: 신고자 제재)은 `/admin/users/<id>`에서 한다.
