# 06 판매 중지 vs 게시중단

둘 다 `/admin/recipes`(또는 신고함 결정)에서 한다. 사유는 필수(`rights_claim`·`policy_violation`·`misleading`·`quality`·`other`)이고 크리에이터와 상세 화면에 보인다.

| | 판매 중지 (`stopped`) | 게시중단 (`taken_down`) |
|---|---|---|
| 쓰는 때 | 결과가 설명과 다름, 품질, 가벼운 정책 위반 | 불법, 권리 침해, 위험한 지시 |
| 할 수 있는 상태 | 공개 중(`live`)만 | 공개 중·판매 중지·비공개·심사 중 |
| 새로 받기 | 안 됨 | 안 됨 |
| 이미 받은 사람 | **받은 버전을 계속 씀**(원문·파일·플레이그라운드) | **못 씀**(원문·파일·업데이트 모두 막힘) |
| 상세 주소 | 대체 화면(사유 + 비슷한 레시피, STOP) | 없는 레시피처럼 보임 |
| 검색·마켓·갤러리 | 빠짐 | 빠짐 |
| 결과물 | 공개 버킷에 남음 | 비공개 버킷으로 옮김(D18) |
| 새 버전 | 제출·승인 가능, 승인해도 판매 중지 유지 | 제출·승인 막힘(반려로만 닫힘) |
| 크리에이터 알림 | 「판매를 멈췄어요」 + 사유 | 「게시를 중단했어요」 + 사유 + 고객센터 안내 |
| 되돌리기 | 「복원하기」 → 다시 공개(승인된 버전이 있을 때만) | 「복원하기」 → **게시중단 직전 상태 그대로** |
| 되돌리기 메모 | 필수 | 필수 |

## 운영이 못 여는 판매 중지
- **크리에이터가 직접 멈춘 레시피**(`stopped_reason = creator_request`, 탈퇴로 멈춘 것 포함)는 운영이 다시 열 수 없다(`CREATOR_STOPPED`). 크리에이터만 연다.
- 승인된 버전이 없으면 다시 열 수 없다(`NO_APPROVED_VERSION`). 심사부터 한다.
- 탈퇴한 크리에이터의 레시피도 다시 열 수 없다(`OWNER_WITHDRAWN`).

## 고르는 기준
1. 받은 사람이 계속 써도 해가 없나? → 판매 중지
2. 받은 사람에게도 남아 있으면 안 되나(불법·권리 침해·악성)? → 게시중단
3. 망설여지면 게시중단으로 먼저 막고, 확인 뒤 복원하거나 판매 중지로 낮춘다(복원 → 다시 판매 중지).

모든 조치는 `admin_actions`(`recipe_stop`·`recipe_takedown`·`recipe_restore`)에 남는다.
