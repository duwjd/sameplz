# 14 콘텐츠 운영

기준은 `docs/content-baseline.md`다. MVP 레시피는 전부 무료다.

## 운영팀 콘텐츠
- 운영팀 레시피·결과물은 **「SAMEPLZ 운영팀」 계정**으로만 올리고, 카드에 운영팀 표시를 한다.
- **가짜 크리에이터, 가짜 SAME 인증은 만들지 않는다.** 기준: "WSJ 1면에 실려도 부끄럽지 않은가".
- 운영팀 결과물에도 「AI 생성」 표시.
- 세무·법률 레시피는 검토 보조로만. 「세무사 검수」 배지는 증빙이 있을 때만. "검증·인증·보장" 문구 금지.

## 갤러리
- 출시 첫 2주는 **원본 60 : SAME 40**으로 섞는다.
- 같은 레시피 결과가 **연속 3장을 넘지 않게** 한다.
- 크레딧을 주는 SAME 인증(예: 「첫 SAME 챌린지」)에는 **「이벤트 참여」** 표시를 단다(추천·보증 심사지침).
- 첫 40건 캡션에는 "어떤 입력으로 했는지" 한 줄을 받는다.

## 컬렉션
- 출시 때 팩 6개 × 레시피 6~8개, 이후 **주 1팩**.
- 팩마다 제목·소개·커버(결과물 3장)·추천 이유 1줄, 다운로드 하위 50% 레시피를 2개 이상 넣는다.

## 홈 섹션
| 섹션 | 규칙 |
|---|---|
| HOME-02 | 무료 1~2개 포함, 크리에이터당 최대 1개 |
| HOME-03 | 크리에이터당 최대 2개, 운영팀 최대 3개(운영팀 카드 표시) |
| HOME-04 | 12~16개 노출(풀 160+) |
| HOME-05 | 6~8명 |

## 수량 점검 (매주)
- 공개 중 레시피 60(최소 40), 직무 9개마다 공개 중 4개 이상(최소 3), 실사용자 SAME 인증 40건 이상.
- 운영팀 누적 목표: W7 35개. 부족한 직무부터 채운다(상세페이지·블로그·카드뉴스·문서 작업 우선).
- 숫자는 `docs/launch-checklist.md`의 SQL로 본다.

## 리스팅 규칙
모든 [변수]를 채운 테스트 입력, 자르거나 보정하지 않은 결과물(R02), 가격·할인·별점 글자가 없는 썸네일(R14).
