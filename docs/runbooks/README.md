# 런북 (MVP는 W7까지 작성)

14종. MVP(무료 출시)에는 01 지급·02 환불이 필요 없어 **유료 전환 단계**에 쓴다. 나머지는 법정 기한이 걸린 것부터 W7까지 쓴다. 파일 이름은 `<번호>-<slug>.md`.
