> **MVP 범위**: 로그인 수단(마지막 수단은 해제 불가, 네이버는 해제 버튼 없음)·선택 알림 3종 끄기·로그아웃·탈퇴(익명화 soft delete → 같은 계정으로 다시 로그인하면 새 회원). 마케팅 수신 동의(무료 MVP에 마케팅 발송이 없다)와 탈퇴 안내의 「거래 기록 5년 보관」 문구(결제가 없다)는 유료 전환 때(2026-10-15).

## 목적

로그인 수단, 판매자 정보, 알림 설정, 로그아웃과 회원 탈퇴.

## 아이템

- **ACC-01** 로그인 수단: 카카오·네이버·구글 연결 상태와 이메일.
- **ACC-02** 판매자 정보: 본인인증·정산 계좌·원천징수 동의.
- **ACC-03** 알림 설정: 필수는 항상 켜짐, 나머지는 끌 수 있음.
- **ACC-04** 로그아웃 · 탈퇴: 탈퇴는 확인 팝업을 거친다.

### 필수 콘텐츠 (보고서 F 묶음에서)

- **로그인 팝업**: 카카오·네이버(D4-B)·구글(이메일 로그인은 MVP 제외, 2026-10-13), 처음이면 자동 가입 → 첫 로그인은 `/welcome`에서 약관·개인정보·만 18세 확인 뒤 완료(F7-9), 가입 혜택 문구는 크레딧 기능(W5) 때 추가, 서버 오류 시 창 유지
- **ACC-01~04 · m:withdraw**: 로그인 수단 연결 상태, 판매자 정보, 알림 스위치(필수는 항상 켜짐), 채널별 마케팅 동의, 탈퇴 팝업(사라지는 것·남는 것, 5년 보관 고지, 「크레딧 환불 먼저」)

## 동작

- 로그인 수단 연결·해제
- 판매자 정보 등록·정산 계좌 바꾸기 → 판매자 정보 팝업
- 알림 스위치 → 해당 알림이 더 이상 오지 않음(업데이트·SAME 인증·팔로우)
- 마케팅 수신 동의 → 동의일 기록
- 회원 탈퇴 → 탈퇴 팝업

## 규칙 (rl)

- 로그인 수단은 하나 이상 남아야 함
- 필수 알림(결제·환불·정산·사람 확인·판매 중지·신고 답변)은 끌 수 없음
- 정산 대기 금액이 있으면 탈퇴 불가

## 경우의 수 (c)

- 마지막 로그인 수단 해제: 막고 안내
- 정산 대기(크리에이터): 탈퇴 버튼 꺼짐
- 탈퇴하면 받은 레시피·크레딧 소멸, SAME 인증은 「탈퇴한 회원」으로 남음

## 팝업

### m:withdraw · 회원 탈퇴 (팝업)

- 설명: 탈퇴하면 사라지는 것과 남는 것을 먼저 보여 주고, 막는 조건이 있으면 버튼을 끈다.
- 동작: 떠나는 이유(선택) · 확인 체크(필수) → 탈퇴 → 비회원 홈
- 규칙: 정산 대기 금액이 있으면 탈퇴 불가
- 규칙: 구매·정산 기록은 5년 보관
- 경우: 확인 체크 안 함: 오류
- 경우: 충전 크레딧이 남음: 「크레딧 환불 먼저」 버튼
