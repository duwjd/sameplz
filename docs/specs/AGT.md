## 목적

동작 단계가 첫 화면. 예시 실행 로그로 무엇을 하는지 보여 주고, 하는 일·안 하는 일을 쉬운 말로 적는다.

## 아이템

- **AGT-01** 동작 흐름: 입력부터 결과까지 단계를 박스로.
- **AGT-02** 인기 지표: 다운로드·SAME·좋아요·업데이트일.
- **AGT-03** 예시 실행: 실제로 돌린 로그를 재생. 실행은 받은 사람 계정에서, 비용도 그 계정에서.
- **AGT-04** 실행 환경·연동: 실행 환경, 연결할 서비스, 받는 사람이 준비할 것.
- **AGT-05** 하는 일·안 하는 일: 권한을 쉬운 말로. 외부 전송·자동 게시 여부.
- **AGT-06** SAME 하기 (상태별): 프롬프트 상세와 같은 규칙. 에이전트는 플레이그라운드 실행 대신 설치 안내로 이어진다.
- **AGT-07** 전문 영역 고지: 세무·법률은 검토 보조만. 자격 증빙이 있을 때만 배지.
- **AGT-08** 상황 띠: 링크로 들어옴 · 사람 확인 중 · 반려 같은 상태를 맨 위에.

### 필수 콘텐츠 (보고서 F 묶음에서)

- **AGT-01~08**: 동작 흐름 박스, 예시 실행 로그 재생, 실행 환경·연동·준비물, 하는 일·안 하는 일(외부 전송·자동 게시·파일 삭제/수정·결제 실행 여부), 세무·법률 고지 띠와 증빙이 있을 때만 「세무사 검수」 배지
- **공통**: 판매자 블록(사업자: 상호·대표자·주소·전화·이메일·사업자번호·신고번호를 청약 전에 표시 / 개인: 「본인인증 완료 판매자」와 분쟁 해결용 정보 요청 경로), 구매 버튼 위 철회 제한 고지 + "미리보기·체험 1회로 먼저 확인할 수 있어요", 결과물의 「AI 생성」 표시

## 동작

- 「예시 실행 보기」는 실제로 돌린 기록을 한 줄씩 재생
- SAME 하면 설정 파일과 설치 안내
- 플레이그라운드 실행은 2단계(지금은 안내 화면)

## 규칙 (rl)

- 에이전트는 모두 사람 확인 뒤 공개(외부 실행)
- 실행 비용은 받은 사람 계정에서
- 세무·법률은 검토 보조만 · 자격 증빙이 있을 때만 배지

## 경우의 수 (c)

- 전문 영역(종합소득세): 상단 고지 띠 + 「세무사 검수」 배지
- 내 에이전트가 사람 확인 중: 나에게만 보이고 상태 띠
- 반려: 사유 + 「고쳐서 다시 제출」

## 예외 (EX)

- [ ] 예시 실행 보기
- [ ] 전문 영역 (세무)
- [ ] 비회원이 SAME 하기 → 로그인
- [ ] 내 에이전트 · 사람 확인 중
- [ ] 내 에이전트 · 반려됨
- [ ] 플레이그라운드로 열면 (2단계 안내)

## 데이터 · API

`getRecipePublic(publicId)`(태그 `recipe:{id}`), `getViewerState(recipeId)`(동적), 액션 `toggleLike`·`toggleFollow`·`createReport`·`recordShareClick`, `generateMetadata`, `opengraph-image.tsx`(한글 폰트 포함). 상세는 SSR로 실제 텍스트를 HTML에 담는다(네이버는 SPA에 SSR 권장). 원문은 담지 않는다.
