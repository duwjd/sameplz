# CRD · 크레딧

- 경로: `/my/credits`
- 와이어프레임: `docs/wireframe/sameplz-wireframe-v0.5.html` (key `credits`), 인벤토리 `docs/wireframe/_context_wireframe_inventory.md`
- 기능 묶음: [F4](F4-playground-credits.md) — F4 플레이그라운드·크레딧 — PLAY · CRD
- 의존 결정: D3, D5, D6, D8 (`docs/decisions.md`) — open이면 해당 부분은 멈추고 묻는다

> **MVP 범위**: 충전(CRD-02, m:charge)과 환불(m:crRefund, F4-10)은 **유료 전환 단계**다. MVP의 `/my/credits`는 **월 무료 크레딧 잔액·다음 리셋 날짜·오늘 남은 한도(CRD-01), 내역(CRD-03: 지급·사용·반환·소멸), 오류 규칙(CRD-04: 모델 오류 반환·안전 필터 차감 없음)**만 보여 주는 읽기 화면이다(F4-14·F4-16). 유료·보너스 구분 표시와 충전·환불 문구는 유료 전환 때 쓴다.

## 목적

플레이그라운드 생성에만 쓰는 크레딧의 잔액·충전·내역·환불. GNB의 크레딧 버튼이 여기로 온다.

## 아이템

- **CRD-01** 보유 크레딧: 잔액과 충전·보너스 나눔, 보너스 유효기간.
- **CRD-02** 충전하기: 팩 3종과 단가 안내.
- **CRD-03** 내역: 날짜·내용·증감·잔액. 충전·사용·반환·환불.
- **CRD-04** 오류와 환불 규칙: 모델 오류는 반환, 안전 필터는 차감 없음, 충전분 환불.

### 필수 콘텐츠 (보고서 F 묶음에서)

- **PLAY-07 · CRD-01~04**: 잔액(유료·보너스 나눔, 보너스 유효기간), 충전 팩 3종(5,000원=500C, 10,000원=1,050C, 30,000원=3,300C), 내역(충전·사용·반환·환불·소멸), 규칙(모델 오류 반환, 안전 필터 차감 없음, 유료분 환불, 레시피 구매 불가)
- **m:charge · m:crRefund**: "1크레딧=10원 · 생성에만 사용 · 보너스 먼저 사용 · 유료 유효기간 5년 · 보너스 유효기간 N일 · 결제 후 7일 이내 미사용 시 전액 환불, 이후 미사용 유료분은 X% 공제 후 환불 · 보너스 환불 불가", 미리 체크된 항목 없음

## 동작

- 충전하기 · 팩별 「충전」 → 충전 팝업
- 내역 필터: 전체 · 충전·반환 · 사용·환불
- 플레이그라운드에서 만들면 「사용」 줄이 쌓이고, 모델 오류면 「반환」 줄이 붙음
- 충전 크레딧 환불 → 환불 팝업

## 규칙 (rl)

- 1크레딧 = 10원 · 보너스 크레딧을 먼저 씀 · 보너스는 환불 안 됨
- 레시피 구매에는 못 씀
- 안 쓴 충전 크레딧은 환불(수수료는 약관)

## 경우의 수 (c)

- 충전 크레딧이 없음(보너스만): 환불 버튼 꺼짐 + 이유
- 내역이 없음: 빈 화면 안내

## 팝업

### m:charge · 크레딧 충전 (팝업)

- 설명: 플레이그라운드 생성에만 쓰는 크레딧을 충전한다. 실행하다 모자라면 모자란 만큼 위에 보여 준다.
- 규칙: 5,000원 → 500C · 10,000원 → 1,050C(+5%) · 30,000원 → 3,300C(+10%)
- 규칙: 생성에만 쓰는 자체 크레딧 · 안 쓴 유료 크레딧은 환불
- 경우: 서버 오류: 결제되지 않았다고 안내하고 창 유지

### m:crRefund · 충전 크레딧 환불 (팝업)

- 설명: 안 쓴 충전 크레딧을 결제 수단으로 돌려준다.
- 동작: 환불 크레딧과 예상 금액 확인 → 환불 신청 → 크레딧 내역에 줄 · 알림
- 규칙: 보너스 크레딧은 환불 안 됨 · 수수료는 약관
- 경우: 서버 오류: 창 유지

## 데이터 · API

`credit_*`·`play_*` 테이블, RPC `start_run`·`place_hold`·`settle_cell`·`grant_purchase`·`request_paid_refund`·`expire_bonus`, 라우트 `POST /api/play/runs`·`POST /api/webhooks/generation/[provider]`·`/api/cron/play-sweeper`, 비공개 채널 `run:{run_id}`. 크레딧 설계는 로트별 행, 한 트랜잭션 안의 잔액 감소와 원장 기록, `FOR UPDATE` 직렬화, 멱등 키, 무료 크레딧 먼저 쓰기. 단가는 `크레딧 ≈ 공급자 USD × 1,450 × 1.8 ÷ 8.75 ≈ USD × 298`(`.claude/skills/generation-pipeline/models.md`). 실패 처리 24행은 `.claude/skills/generation-pipeline/failure-matrix.md`.
