# F1 탐색 — HOME · MKT · COL · NF

> 쏠림을 누르는 랭킹 규칙이 핵심이다

- 화면 명세: [HOME](HOME.md) · [MKT](MKT.md) · [COL](COL.md) · [NF](NF.md)
- 우선순위: P0(빠지면 출시 불가) · P1(출시 후 4~8주) · P2(설계만 대비)
- 수용 기준은 Given → When → Then을 줄인 것이고, 와이어프레임 예외(EX)·시나리오(SCN)에 대응한다. 테스트 이름에 요구사항 ID를 넣는다.

## 문제

처음 온 사람은 로그인 없이 구경하다 1분 안에 쓸 만한 레시피를 찾아야 한다. 그런데 스킬 설치는 상위 1.2%가 94%를 가져간다(Vercel, State of Agent Skills). 단순 인기순은 새 크리에이터를 묻어 버린다.

## 목표

- 첫 방문에서 상세 진입
- 검색 0건 막다른 길 제거
- "공정해 보이는" 랭킹

## 비목표

- 개인화 추천(P2)
- 카테고리 입구 카드(와이어프레임에서 제외)
- 외부 검색 엔진(5천 MAU에서는 동기화 비용만 늘림)
