# F2 상세 — PRM · AGT · SKL · STOP

> 원문 대신 증거를 보여 주고 버튼은 상태당 하나다

- 화면 명세: [PRM](PRM.md) · [AGT](AGT.md) · [SKL](SKL.md) · [STOP](STOP.md)
- 의존 결정: D9 (`docs/decisions.md`)
- 우선순위: P0(빠지면 출시 불가) · P1(출시 후 4~8주) · P2(설계만 대비)
- 수용 기준은 Given → When → Then을 줄인 것이고, 와이어프레임 예외(EX)·시나리오(SCN)에 대응한다. 테스트 이름에 요구사항 ID를 넣는다.

## 문제

구매자는 원문을 보지 못한 채 결과물·변수·실행 기록만으로 판단한다. 디지털콘텐츠 청약철회를 제한하려면 철회 불가 표시와 시험 사용을 함께 갖춰야 하고, 제한 사유와 표시 의무 이행은 사업자가 증명한다(대법원 2018다214746). 상세 화면의 결과물·변수·호출 예시·실행 로그는 판매 콘텐츠이면서 법적 증거다.

## 목표

- 증거를 먼저 보여 주는 첫 화면
- 상태별 주 버튼 하나
- 상태 띠

## 비목표

- 별점·리뷰(와이어프레임에 없음)
- 에이전트·스킬의 플레이그라운드 실행(2단계)

## 필수 콘텐츠

| 아이템 | 필수 콘텐츠 |
|---|---|
| PRM-01~08 | 결과물 갤러리(영상 9:16 그대로), 다운로드·SAME·좋아요·업데이트일, 사용 도구·설정, [변수] 미리보기(본문 가림), 따라 만든 결과, 상태별 주 버튼, 「바로 만들어 보기」(API 없는 도구면 꺼짐 + 이유), 상황 띠(링크로 들어옴·검토 중·반려) |
| AGT-01~08 | 동작 흐름 박스, 예시 실행 로그 재생, 실행 환경·연동·준비물, 하는 일·안 하는 일(외부 전송·자동 게시·파일 삭제/수정·결제 실행 여부), 세무·법률 고지 띠와 증빙이 있을 때만 「세무사 검수」 배지 |
| SKL-01~08 | 대화 모양 호출 예시, 전후 비교, 도구 탭별 설치 3단계와 복사(막히면 m:copy), 파일 구성(이름만), 안전 검사 태그(「스크립트 있음 · 사람 확인 완료」) |
| STOP-01~03 | 중지 사유(코드 5~6종 문구), 받은 사람용 「받은 버전 열기」, 비슷한 레시피 3개 |
| 공통 | 판매자 블록(사업자: 상호·대표자·주소·전화·이메일·사업자번호·신고번호를 청약 전에 표시 / 개인: 「본인인증 완료 판매자」와 분쟁 해결용 정보 요청 경로), 구매 버튼 위 철회 제한 고지 + "미리보기·체험 1회로 먼저 확인할 수 있어요", 결과물의 「AI 생성」 표시 |

## 데이터 · API

`getRecipePublic(publicId)`(태그 `recipe:{id}`), `getViewerState(recipeId)`(동적), 액션 `toggleLike`·`toggleFollow`·`createReport`·`recordShareClick`, `generateMetadata`, `opengraph-image.tsx`(한글 폰트 포함). 상세는 SSR로 실제 텍스트를 HTML에 담는다(네이버는 SPA에 SSR 권장). 원문은 담지 않는다.
