# HOME · 홈

- 경로: `/`
- 와이어프레임: `docs/wireframe/sameplz-wireframe-v0.5.html` (key `home`), 인벤토리 `docs/wireframe/_context_wireframe_inventory.md`
- 기능 묶음: [F1](F1-discovery.md) — F1 탐색 — HOME · MKT · COL · NF

## 목적

구경이 먼저인 첫 화면. 롤링 배너 아래로 이번 주 다운로드 많은 → 실시간 인기 TOP 10 → 지금 뜨는 결과물 → 인기 크리에이터 순서.

## 아이템

- **HOME-01** 롤링 배너: 4장이 5초마다 넘어간다. 멈춤·이전·다음 버튼과 번호 표시(1 / 4), 장마다 이름 버튼. 마우스를 올리거나 포커스가 들어오면 멈춘다.
- **HOME-02** 이번 주 다운로드 많은: 최근 7일 받은 수 기준 4개. 무료 레시피도 섞어 처음 온 사람이 바로 받아 보게 한다.
- **HOME-03** 실시간 인기 TOP 10: 목록 대신 큰 순위 숫자와 카드를 가로로 넘기는 띠. ▲▼로 1시간 전 대비 변동을 보여 “지금 뜨는 것”을 만든다.
- **HOME-04** 지금 뜨는 결과물: 갤러리 미리보기. 결과물이 먼저, 레시피는 한 번 누르면 나온다.
- **HOME-05** 인기 크리에이터: 팔로우하면 새 레시피 알림이 온다. 비회원이 누르면 로그인 창이 먼저 뜬다.
- **HOME-06** 통신판매중개 고지: 법적 고지는 초기화면 푸터에 둔다(전자상거래법 제20조).

### 필수 콘텐츠 (보고서 F 묶음에서)

- **HOME-01**: 배너 4장(서비스 소개·플레이그라운드·이번 주 컬렉션·크리에이터 모집), 장마다 이미지·제목 20자·부제 30자·버튼·대체 텍스트·장 이름 버튼 라벨 — 출처 E · 4장 + 예비 1세트. 컬렉션 배너는 주 1회, 나머지는 월~분기
- **HOME-02**: 최근 7일 받은 수 상위 4개(무료 1~2 포함), 크리에이터당 최대 1개 — 출처 S
- **HOME-03**: TOP 10 순위 카드, 1시간 전 대비 ▲▼, 크리에이터당 최대 2개·운영팀 최대 3개(운영팀 카드 표시) — 출처 S
- **HOME-04 · 05**: 결과물 12~16개 노출(풀 160+), 인기 크리에이터 6~8명(사진·닉네임·소개·대표 레시피) — 출처 U+S
- **HOME-06**: 통신판매중개 고지 + 상호·대표자·주소·전화·이메일·사업자등록번호·통신판매업 신고번호·호스팅 제공자·약관·**개인정보처리방침(굵게)** — 출처 E(법무). 초기화면에 상호·대표자·주소·약관 링크 표시 의무

## 동작

- 배너는 5초마다 넘어가고, 마우스를 올리거나 배너 안에 포커스가 있으면 멈춤
- 배너의 멈춤·이전·다음·번호 버튼으로 직접 넘기면 자동 넘김이 꺼짐
- TOP 10은 가로로 넘기는 순위 카드 · 탭을 바꾸면 순위만 다시 그림
- 「전체 보기」 → 마켓 전체(다운로드순)
- 결과물의 「같은 걸로」 → 원본 레시피 상세
- 팔로우는 로그인 뒤 하던 일로 이어짐

## 규칙 (rl)

- 배너 4장: 서비스 소개 · 플레이그라운드 · 이번 주 컬렉션 · 크리에이터 모집
- 움직임 줄이기를 켠 사람에겐 자동 넘김을 처음부터 멈춤(WCAG 2.2.2)
- 순위·다운로드 TOP에는 판매 중인 레시피만 · 인기 점수 = 다운로드 + SAME×4 + 좋아요×0.5
- 카테고리 입구 카드는 없음 · 카테고리는 GNB 마켓 메뉴에서

## 경우의 수 (c)

- 비회원: GNB 오른쪽은 로그인 하나 · 팔로우·「판매 시작하기」는 로그인 창부터
- 회원: GNB 오른쪽은 알림 · 크레딧 · 마이페이지
- 모바일: 배너 이미지가 위, 글이 아래 · 순위는 손가락으로 넘김

## 예외 (EX)

- [ ] 비회원이 처음 들어옴
- [ ] 비회원이 팔로우
- [ ] 비회원이 「판매 시작하기」 배너 → 로그인
- [ ] 배너를 직접 넘김 → 자동 넘김 멈춤
- [ ] 마켓 하위 메뉴 펼침 (호버 상태)
- [ ] 검색 결과 없음 → 인기 검색어
- [ ] 연결 끊김
