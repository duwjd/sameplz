# MY · 마이페이지 홈

- 경로: `/my`
- 와이어프레임: `docs/wireframe/sameplz-wireframe-v0.5.html` (key `my`), 인벤토리 `docs/wireframe/_context_wireframe_inventory.md`
- 기능 묶음: [F7](F7-account-notifications-policy.md) — F7 계정·알림·정책 — MY · NOTI · PRF · ACC · GUIDE · 로그인
- 의존 결정: D3, D4, D5 (`docs/decisions.md`) — open이면 해당 부분은 멈추고 묻는다

> **MVP 범위**: 숫자 타일(받은 레시피·크레딧·좋아요·팔로잉·SAME 인증)·최근 받은 레시피 3개(MY-04)·업데이트 안내·판매자 센터·최근 알림과, 모든 마이페이지 화면의 같은 메뉴(MY-07, 폰은 가로 스크롤)만. 좋아요 타일은 숫자만 보여 준다(좋아요한 레시피 목록 화면이 없다). MY-03의 그 자리 「업데이트하기」는 라이브러리로 보낸다(W6 구현에서 뺌, 2026-10-15).

## 목적

GNB 오른쪽 마이페이지(아바타)로 들어온다. 내 정보 요약과 할 일을 모으고, 왼쪽 메뉴로 라이브러리·구매 내역·크레딧·알림·내 활동·판매자 센터·설정으로 간다.

## 아이템

- **MY-01** 프로필 요약: 닉네임·핸들·가입일·판매자 인증 상태·소개. 「프로필 편집」으로.
- **MY-02** 숫자 타일: 받은 레시피·크레딧·좋아요·팔로잉·SAME 인증. 누르면 그 화면으로.
- **MY-03** 업데이트가 있어요: 받은 버전보다 새 버전이 있는 레시피. 여기서 바로 업데이트.
- **MY-04** 최근 받은 레시피: 최근 3개와 상태, 원문 열기.
- **MY-05** 판매자 센터 카드: 판매 중이면 30일 매출·다운로드·SAME, 아니면 올리기 안내.
- **MY-06** 최근 알림: 최근 3개. 전체는 알림 화면.
- **MY-07** 마이페이지 메뉴: 모든 마이페이지 화면에 같은 메뉴. 라이브러리 업데이트 수와 안 읽은 알림 수를 붙인다.

### 필수 콘텐츠 (보고서 F 묶음에서)

- **로그인 팝업**: 카카오·네이버(D4-B)·구글(이메일 로그인은 MVP 제외, 2026-10-13), 처음이면 자동 가입 → 첫 로그인은 `/welcome`에서 약관·개인정보·만 18세 확인 뒤 완료(F7-9), 가입 혜택 문구는 크레딧 기능(W5) 때 추가, 서버 오류 시 창 유지
- **MY-01~07**: 프로필 요약, 숫자 타일 5개와 새 회원용 다음 할 일 문장, 업데이트 줄, 최근 받은 레시피 3개, 판매자 카드 2상태, 최근 알림 3개, 메뉴(라이브러리 업데이트 수·안 읽은 알림 수 배지)

## 동작

- 숫자 타일(받은 레시피·크레딧·좋아요·팔로잉·SAME 인증)을 누르면 해당 화면·탭으로
- 업데이트 줄에서 바로 업데이트
- 판매자 센터 카드: 판매 중이면 30일 숫자, 아니면 「레시피 올리기」
- 로그아웃은 메뉴 맨 아래

## 규칙 (rl)

- 마이페이지 메뉴: 내 레시피(라이브러리·구매 내역·크레딧) · 활동(알림·SAME 인증·팔로잉) · 판매(판매자 센터) · 설정(프로필·계정·알림 설정)
- 데스크톱은 왼쪽 메뉴, 모바일은 위쪽 가로 메뉴

## 경우의 수 (c)

- 비회원이 /my 주소로 오면 로그인 안내 → 로그인 뒤 마이페이지
- 새로 가입한 회원: 숫자는 0, 각 칸에 다음 할 일 안내

## 팝업

### m:login · 로그인 (팝업)

- 설명: 받기·좋아요·팔로우·올리기·실행 직전에 뜬다. 하려던 일을 기억했다가 로그인 뒤 바로 이어서 한다.
- 동작: 카카오 · 네이버 · 구글 · 이메일 · 처음이면 자동 가입
- 동작: 와이어프레임: 어느 버튼이든 지우로 로그인(로그인 만료 뒤에는 원래 계정)
- 경우: 창을 닫으면 하려던 일 취소
- 경우: 서버 오류: 창을 그대로 두고 다시 시도
