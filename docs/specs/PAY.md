# PAY · 결제

- 경로: `/checkout`
- 와이어프레임: `docs/wireframe/sameplz-wireframe-v0.5.html` (key `checkout`), 인벤토리 `docs/wireframe/_context_wireframe_inventory.md`
- 기능 묶음: [F3](F3-checkout-library.md) — F3 결제·라이브러리 — PAY · LIB · ORD
- 의존 결정: D1, D6, D9 (`docs/decisions.md`) — open이면 해당 부분은 멈추고 묻는다

> **MVP 범위**: **이 화면 전체가 유료 전환 단계(사업자등록·PG 계약·통신판매업 신고 후)다.** MVP에는 `/checkout`이 없고, 상세의 받기 버튼은 무료 받기(`claim_free_recipe`)로 바로 라이브러리에 간다. 아래 내용은 유료 전환 때 그대로 쓴다.

## 목적

주문 확인과 결제를 한 화면에서. 유입 경로(직접 5% · 마켓 15%)와 철회 제한 동의를 보여 준다.

## 아이템

- **PAY-01** 단계 표시: 주문 확인 → 결제 → 완료.
- **PAY-02** 쿠폰: 만든 크리에이터의 레시피에만 적용. 쿠폰을 쓰면 직접 유입으로 잡힌다.
- **PAY-03** 필수 동의: 철회 제한 동의 없이는 결제 버튼이 비활성.
- **PAY-04** 통신판매중개 고지: 거래 당사자가 아님을 결제 단계에서도 고지.
- **PAY-05** 유입 표시: 공유 링크로 들어왔으면 “직접 유입(수수료 5%)”. 판매자 대시보드 숫자로 이어진다.

### 필수 콘텐츠 (보고서 F 묶음에서)

- **PAY-01~05**: 단계 표시(주문 확인 → 결제 → 완료), 쿠폰 칸과 오류 2종(없는 코드 / 다른 크리에이터 쿠폰), 필수 동의 ① "원문을 열거나 파일을 받으면 디지털콘텐츠 제공이 시작되어 청약철회가 제한됨에 동의합니다(열기 전 7일 이내 전액 환불)" ② "주문 내용 확인 및 결제 진행 동의", 통신판매중개 고지, 판매자 본인인증 표시, 유입 표시("직접 유입(수수료 5%)")
- **PAY 오류**: 한도 초과 "결제되지 않았어요" + 「다시 결제하기」, 결제창 닫음(선택 유지), 연결 끊김, 이미 받음·내 레시피·판매 중지 차단 문구

## 동작

- 쿠폰 적용 → 할인과 「직접 유입」 표시
- 필수 동의 2개를 모두 체크해야 결제 버튼이 켜짐
- 결제 → 완료 단계 → 라이브러리 / 플레이그라운드(체험에서 왔으면 강조)

## 규칙 (rl)

- 크리에이터 쿠폰은 그 크리에이터 레시피에만
- 크레딧으로는 결제 불가
- 통신판매중개 고지 · 판매자 본인인증 표시

## 경우의 수 (c)

- 없는 쿠폰 코드와 다른 크리에이터 쿠폰을 나눠 안내
- 카드 한도 초과: 「결제되지 않았어요」 + 다른 수단 · 버튼은 「다시 결제하기」
- 결제창 닫음: 고른 내용 유지
- 이미 받음 · 내 레시피 · 판매 중지: 결제를 막고 안내
- 비회원: 로그인 뒤 결제로 돌아옴

- [ ] 동의 전 · 결제 버튼 꺼짐
- [ ] 없는 쿠폰 코드
- [ ] 다른 크리에이터 쿠폰
- [ ] 쿠폰 적용 · 직접 유입
- [ ] 카드 한도 초과
- [ ] 결제창 닫음
- [ ] 결제 중 서버 오류
- [ ] 연결 끊김 · 결제 버튼 멈춤
- [ ] 이미 받은 레시피를 결제
- [ ] 내 레시피를 결제
- [ ] 판매 중지된 레시피를 결제
- [ ] 공유 링크로 들어온 구매
- [ ] 결제 완료

## 데이터 · API

거래 묶음 테이블(`orders`, `refunds`, `entitlements`, `entitlement_version_history`, `coupons`, `coupon_redemptions`, `share_links`, `share_link_clicks`, `private.webhook_events`), RPC `get_checkout_quote`·`create_pending_order`·`claim_free_recipe`·`confirm_order_paid`·`refund_order`·`open_original`·`apply_update`, 라우트 `/api/webhooks/toss`·`/api/files/[versionId]`. 토스 웹훅 이벤트는 `PAYMENT_STATUS_CHANGED`와 `CANCEL_STATUS_CHANGED`. 2025년 2월 시행 다크패턴 규정에 첫 과태료가 나왔으므로 미리 체크된 선택지는 두지 않고 총액을 먼저 보여 준다.
