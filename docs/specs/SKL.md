# SKL · 스킬 상세

- 경로: `/r/[id]` (category=skill)
- 와이어프레임: `docs/wireframe/sameplz-wireframe-v0.5.html` (key `item-skill`), 인벤토리 `docs/wireframe/_context_wireframe_inventory.md`
- 기능 묶음: [F2](F2-detail.md) — F2 상세 — PRM · AGT · SKL · STOP
- 의존 결정: D9 (`docs/decisions.md`) — open이면 해당 부분은 멈추고 묻는다

## 목적

호출 예시(대화 모양)가 첫 화면. 전후 비교와 도구별 설치 3단계, 설치 명령 복사.

## 아이템

- **SKL-01** 이렇게 말하면 작동해요: 호출 예시를 대화 모양으로.
- **SKL-02** 인기 지표: 다운로드·SAME·좋아요·업데이트일.
- **SKL-03** 전후 비교: 넣은 것과 나온 것.
- **SKL-04** 설치 안내: 도구별 3단계와 설치 명령(예시 문구).
- **SKL-05** 파일 구성: SKILL.md와 참고 파일. 본문은 받은 뒤.
- **SKL-06** 안전 검사: 작게 표시. 스크립트가 있으면 사람 확인.
- **SKL-07** SAME 하기 (상태별): 프롬프트 상세와 같은 규칙.
- **SKL-08** 상황 띠: 링크로 들어옴 · 내 스킬 상태를 맨 위에.

### 필수 콘텐츠 (보고서 F 묶음에서)

- **SKL-01~08**: 대화 모양 호출 예시, 전후 비교, 도구 탭별 설치 3단계와 복사(막히면 m:copy), 파일 구성(이름만), 안전 검사 태그(「스크립트 있음 · 사람 확인 완료」)
- **공통**: 판매자 블록(사업자: 상호·대표자·주소·전화·이메일·사업자번호·신고번호를 청약 전에 표시 / 개인: 「본인인증 완료 판매자」와 분쟁 해결용 정보 요청 경로), 구매 버튼 위 철회 제한 고지 + "미리보기·체험 1회로 먼저 확인할 수 있어요", 결과물의 「AI 생성」 표시

## 동작

- 설치 안내의 도구 탭을 바꾸면 3단계 문구가 그 도구로 바뀜
- 「복사」 → 클립보드(막히면 복사 창)
- 파일 구성은 이름만, 본문은 받은 뒤

## 규칙 (rl)

- 지침만 있는 스킬은 자동 검사 뒤 바로 공개
- 스크립트가 있으면 샌드박스 실행 + 사람 확인(1~2일)
- 체험 채팅은 2단계

## 경우의 수 (c)

- 스크립트 있음: 「스크립트 있음 · 사람 확인 완료」 태그
- 무료 스킬: 「무료로 SAME 하기」 → 바로 라이브러리
- 이미 받음: 「라이브러리에서 열기」

## 팝업

### m:copy · 복사 (팝업)

- 설명: 클립보드가 막힌 환경에서 직접 골라 복사하도록 보여 준다.
- 동작: 내용이 선택된 채로 열림


## 예외 (EX)

- [ ] 스크립트 있는 스킬
- [ ] 무료 스킬
- [ ] 이미 받은 스킬
- [ ] 설치 명령 복사 (클립보드 막힘)

## 데이터 · API

`getRecipePublic(publicId)`(태그 `recipe:{id}`), `getViewerState(recipeId)`(동적), 액션 `toggleLike`·`toggleFollow`·`createReport`·`recordShareClick`, `generateMetadata`, `opengraph-image.tsx`(한글 폰트 포함). 상세는 SSR로 실제 텍스트를 HTML에 담는다(네이버는 SPA에 SSR 권장). 원문은 담지 않는다.
