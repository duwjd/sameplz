# UP · 판매자 센터 · 레시피 올리기

- 경로: `/my/seller/upload`
- 와이어프레임: `docs/wireframe/sameplz-wireframe-v0.5.html` (key `create`), 인벤토리 `docs/wireframe/_context_wireframe_inventory.md`
- 기능 묶음: [F5](F5-upload-seller.md) — F5 올리기·판매자 센터 — UP · SELL
- 의존 결정: D1, D2, D7, D9, D10 (`docs/decisions.md`) — open이면 해당 부분은 멈추고 묻는다

> **MVP 범위**: **무료 올리기만.** UP-06의 가격 입력·판매 선택·본인인증·정산 정보는 없고 공개 범위(공개·비공개)만 고른다. 결과물은 1개 이상(UP-05). 4단계 끝에 「유료 판매 오픈 알림 신청」 버튼(F5-14)을 둔다. 자동 검사(UP-07)·사람 확인·새 버전 규칙은 그대로. 판매 분기와 m:verify는 **유료 전환 단계**다. 아래 내용은 지우지 않는다.

## 목적

마이페이지 > 판매자 센터 안의 「레시피 올리기」 탭. 카테고리 → 내용 → 결과물 → 공개·가격 → 검사의 5단계.

## 아이템

- **UP-01** 5단계 올리기: 카테고리 → 내용 → 결과물 → 공개·가격 → 검사.
- **UP-02** 카테고리 선택: 프롬프트(이미지·영상·텍스트)·스킬·에이전트.
- **UP-03** GPTs 가져오기: GPT 지침을 스킬 초안으로. 스킬일 때만.
- **UP-04** 카테고리별 입력: 프롬프트: [변수]·설정·레퍼런스 / 스킬: SKILL.md·호출 예시 / 에이전트: 단계·연동.
- **UP-05** 결과물: 무료 1개, 판매 3개 이상. 플레이그라운드 결과를 바로 가져올 수 있다.
- **UP-06** 공개 범위·가격: 판매는 본인인증·정산 정보가 있어야 한다. 라이선스는 하나, 가격도 하나.
- **UP-07** 자동 검사: 숨은 지시문·금지 표현·결과물 수. 스크립트나 외부 실행이 있으면 사람 확인(1~2일).
- **UP-08** 초안·새 버전: 쓰다 나가면 초안이 남고, 돌아오면 이어서 쓸지 묻는다. 새 버전은 변경 내용이 필수.

### 필수 콘텐츠 (보고서 F 묶음에서)

- **UP-01~08**: 5단계 탭(카테고리 → 내용 → 결과물 → 공개·가격 → 검사), 단계별 도움말·placeholder·예시(5단계 × 3카테고리), [변수] 자동 인식, 설명 본문 5블록 템플릿, 플레이그라운드 결과 가져오기, 초안 「이어서 / 새로 시작」, 새 버전 변경 내용 필수, GPTs 가져오기 안내(UP-03)
- **반려 문구 R01~R16**: 결과물 부족, 보정·자름, 너무 비슷함, 재현 실패, 쓰임새 불명, 너무 단순, 유사·표절, 숨은 지시문·보이지 않는 문자, 금지 표현, 전문 영역 단정, 키·비밀번호·개인정보, 「하는 일」 누락, 가짜 실행 로그, 썸네일 가격 글자, 변수 설명 비어 있음, 얼굴·실존 인물·상표 무단 사용. 문구마다 고칠 단계 링크
- **m:verify · 판매자 가이드**: 본인인증 → 주소·이메일 → 정산 계좌(예금주 확인) → 소득 구분과 원천징수·지급대행 동의 → 토스 SMS("정산 받을 계좌 확인 문자가 와요"). 판매자 온보딩 가이드 10장

## 동작

- 단계 탭으로 오가기 · 「다음」은 그 단계 필수값을 확인
- 프롬프트는 [대괄호]를 변수로 자동 인식
- 플레이그라운드 결과 가져오기(실행 기록이 있을 때)
- 검사 통과 → 공개 / 사람 확인 / 비공개 저장 → 내 레시피 상세로

## 규칙 (rl)

- 무료 공유는 결과물 1개 · 판매는 3개 이상
- 판매는 본인인증 · 정산 계좌 · 원천징수 동의가 먼저
- 새 버전은 변경 내용 필수 · 카테고리 변경 불가
- 에이전트·스크립트 스킬은 사람 확인 1~2일

## 경우의 수 (c)

- 제목 없이 다음: 칸 아래 오류 + 포커스
- 가격 1,000원 미만: 오류
- 검사 실패(숨은 지시문·보이지 않는 문자·금지 표현·결과물 수): 「고치러 가기」
- 쓰다 나감: 초안 저장 → 「이어서 / 새로 시작」
- 반려된 레시피: 사유를 보여 주고 다시 제출

## 데이터 · API

`recipe_drafts`·`recipe_versions`·`auto_checks`·`review_queue`·`seller_profiles`·`seller_earnings`·`payouts`·`share_links`·`coupons`·`recipe_daily_stats`, 액션 `saveDraft`(디바운스)·`createSignedUpload`·`submitRecipe`·`registerSeller`·`createShareLink`·`createCoupon`·`stopRecipe`·`setRecipeVisibility`. 크론은 Vercel Cron 화요일 지급 배치와 `pg_cron` 일간 통계·보류 해제. 토스 지급대행 웹훅은 페이로드+타임스탬프 HMAC-SHA256으로 검증.
